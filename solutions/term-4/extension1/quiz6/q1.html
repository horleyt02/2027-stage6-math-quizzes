Problem

Consider: \[ f(x) = \frac{|x|}{x} \] for \( x \neq 0 \)

Which of the following is the graph of \( f(x) \)?

Worked Solution

Step 1: Define the Absolute Value

To simplify \( f(x) \), we must first break the absolute value function, \( |x| \), down into its piecewise definition based on whether \( x \) is positive or negative.

Piecewise Definition:
\[ |x| = \begin{cases} x & \text{for } x > 0 \\ -x & \text{for } x < 0 \end{cases} \]

*Note: We don't evaluate at \( x = 0 \) because the problem explicitly states \( x \neq 0 \).

Step 2: Evaluate the Fraction in Cases

Now substitute these definitions back into the original function \( f(x) = \frac{|x|}{x} \):

Case 1: When \( x > 0 \)

Substitute \( x \) for \( |x| \)

\[ f(x) = \frac{x}{x} = \mathbf{1} \]
Case 2: When \( x < 0 \)

Substitute \( -x \) for \( |x| \)

\[ f(x) = \frac{-x}{x} = \mathbf{-1} \]

Step 3: Construct the Graph

Based on our evaluation, the function behaves as two distinct horizontal lines:

  • A horizontal ray at \( y = 1 \) for all positive values (\( x > 0 \)).
  • A horizontal ray at \( y = -1 \) for all negative values (\( x < 0 \)).
  • Open circles at \( x = 0 \) for both lines, because division by zero is undefined.
Graph C perfectly matches these two separate horizontal rays with holes at the \( y \)-axis.

Therefore, Option C is correct.
