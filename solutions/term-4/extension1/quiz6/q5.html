Problem

A function is defined by \( f(x) = \sqrt{16 - x^2} \) for \( -4 \le x \le 0 \).

Which of the following represents the inverse function \( f^{-1}(x) \)?

Worked Solution

Step 1: Determine the Original Domain and Range

First, let's establish the domain and range of the original function \( f(x) \).

  • Domain (given): \( x \in [-4, 0] \)
  • Range: Evaluate the function at the endpoints of the domain.
    \( f(-4) = \sqrt{16 - (-4)^2} = 0 \)
    \( f(0) = \sqrt{16 - 0^2} = 4 \)
    The range is \( y \in [0, 4] \).

Step 2: Swap for the Inverse

The fundamental property of an inverse function is that the \(x\) and \(y\) values swap. This means the domain and range also swap.

For the inverse function \( f^{-1}(x) \):

New Domain \( 0 \le x \le 4 \)
New Range \( -4 \le y \le 0 \)

Notice that the new range is entirely negative (or zero).

Step 3: Solve Algebraically

Now, set \( x = \sqrt{16 - y^2} \) and solve for \( y \):

\[ x^2 = 16 - y^2 \]
\[ y^2 = 16 - x^2 \]
\[ y = \pm\sqrt{16 - x^2} \]

Because our new range from Step 2 is \( -4 \le y \le 0 \), we must choose the negative root:

\[ f^{-1}(x) = -\sqrt{16 - x^2} \text{ for } 0 \le x \le 4 \]

Therefore, Option A is correct.
