Problem

The diagram below shows the graph of the function \( y = f(x) \).

Which of the following is the graph of \( y = |f(x)| \)?

Worked Solution

Step 1: Recall the Rule for \( y = |f(x)| \)

Taking the absolute value of the function output \( f(x) \) ensures that all \( y \)-values are non-negative (\( y \ge 0 \)):

Any part of the graph above the \( x \)-axis (\( f(x) \ge 0 \)) stays unchanged.
Any part of the graph below the \( x \)-axis (\( f(x) < 0 \)) is reflected upward across the \( x \)-axis.
Vertical asymptotes are not shifted, so the asymptote remains at \( x = -2 \).

Step 2: Apply the Reflection to Each Branch

Look at the two branches separated by the vertical asymptote at \( x = -2 \):

  • Left branch (\( x < -2 \)): Already positive (\( y > 0 \)), so it stays in the exact same position.
  • Right branch (\( x > -2 \)): Entirely negative (\( y < 0 \)), so it flips upward across the \( x \)-axis. For example, the \( y \)-intercept \( (0, -2) \) reflects to \( (0, 2) \).
Unchanged (\( f(x) > 0 \)) Original (\( f(x) < 0 \)) Reflected (\( |f(x)| \))

Step 3: Identify the Matching Graph

The resulting graph of \( y = |f(x)| \) has:

• A vertical asymptote unchanged at \( x = -2 \)
• Both branches entirely above the \( x \)-axis (\( y > 0 \))
• A \( y \)-intercept at \( (0, 2) \)

Therefore, Option A is the correct choice.
