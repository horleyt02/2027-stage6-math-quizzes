Problem

For the domain \( 0 \le x \le 2\pi \), how many solutions does the following equation have?

\[ \sin(2x) - \cos x = 0 \]

Worked Solution

Step 1: Apply the Compound Angle Identity from the reference sheet and Factorise

Substitute \( \sin(2x) = 2\sin x \cos x \) into the equation and factor out the common term \( \cos x \) (do not divide by \( \cos x \)):

\[ 2\sin x \cos x - \cos x = 0 \]
\[ \cos x(2\sin x - 1) = 0 \]

Step 2: Solve Each Factor for \( 0 \le x \le 2\pi \)

Set each factor equal to zero and find all solutions in the domain \( 0 \le x \le 2\pi \):

Case 1: \( \cos x = 0 \)
\[ x = \frac{\pi}{2}, \; \frac{3\pi}{2} \quad (\text{2 solutions}) \]
Case 2: \( 2\sin x - 1 = 0 \implies \sin x = \dfrac{1}{2} \) (Quadrants 1 & 2)
\[ x = \frac{\pi}{6}, \; \frac{5\pi}{6} \quad (\text{2 solutions}) \]

Step 3: Verify Graphically via Intersection Points

Rewriting the equation as \( \sin(2x) = \cos x \), the solutions are the intersection points of \( y = \sin(2x) \) and \( y = \cos x \) on \( [0, 2\pi] \):

\( y = \sin(2x) \) \( y = \cos x \) 4 Intersections
\[ x = \frac{\pi}{6}, \; \frac{\pi}{2}, \; \frac{5\pi}{6}, \; \frac{3\pi}{2} \implies 4 \text{ solutions} \]

Therefore, Option C is the correct choice.
