Problem

What is the solution to the following inequality?

\[ \frac{x + 3}{x - 2} > 0 \]

Worked Solution

Step 1: Find the Critical Values

A rational expression can only change sign where its numerator is zero or its denominator is zero (undefined):

\[ \text{Numerator } = 0: \quad x + 3 = 0 \implies x = -3 \]
\[ \text{Denominator } = 0: \quad x - 2 = 0 \implies x = 2 \quad (x \neq 2) \]

Because the inequality is strictly (\( > 0 \)) and the denominator cannot be zero, neither critical value is included in the solution (both use open circles).

Step 2: Sketch the Parabola to Check the Sign Regions

A quotient \( \frac{x + 3}{x - 2} \) has the exact same sign as the product \( y = (x + 3)(x - 2) \) (for \( x \neq 2 \)). Sketch the concave up parabola through the critical values \( x = -3 \) and \( x = 2 \):
