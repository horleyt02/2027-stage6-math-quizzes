Problem

The graph of a cubic \( y = h(x) \) function is shown below.

It has \( x \)-intercepts at \( x = c, x = 0 \) and \( x = d \), and has turning points where \( x = a \) and \( x = b \).

Which of the following restrictions on the domain would allow the function \( h(x) \) to have an inverse function \( y = h^{-1}(x) \)?

Worked Solution

Step 1: The Horizontal Line Test

For a function to have an inverse, it must be one-to-one. This means no two different \(x\)-values can share the same \(y\)-value.

Visually, this means the graph must pass the Horizontal Line Test: any horizontal line must intersect the graph at most once.

Step 2: Identify the Turning Points

Turning points (local maxima and minima) are the exact locations where a graph changes direction from increasing to decreasing, or vice versa.

  • There is a local minimum at \( x = a \).
  • There is a local maximum at \( x = b \).

If an interval contains a turning point, the graph will "turn back" on itself, causing horizontal lines to intersect it multiple times.

Step 3: Evaluate the Intervals

To pass the test, we must restrict the domain to a section of the graph that is strictly increasing or strictly decreasing, completely avoiding crossing over any turning points.

  • \( [c, 0] \) contains the turning point \( a \). Fails.
  • \( [c, d] \) contains both turning points \( a \) and \( b \). Fails.
  • \( [0, \infty) \) contains the turning point \( b \). Fails.
  • \( [a, b] \) is exactly the region between the turning points. It is strictly increasing. Passes!

Step 4: Conclusion

Restricting the domain to the interval between the two turning points ensures the function is one-to-one.

Option B: \( [a, b] \)

Therefore, Option B is correct.
