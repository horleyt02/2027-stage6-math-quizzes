Problem

The polynomial \( P(x) = 3x^3 - x^2 - 6x - 9 \) has roots \( \alpha \), \( \beta \) and \( \gamma \).

What is the value of the following?

\[ \frac{1}{\gamma} + \frac{1}{\beta} + \frac{1}{\alpha} \]

Worked Solution

Step 1: Check the Reference Sheet Formulas

From the Functions section on the reference sheet, for any cubic equation \( ax^3 + bx^2 + cx + d = 0 \):

From the Reference Sheet:
\[ \alpha + \beta + \gamma = -\frac{b}{a} \]
\[ \alpha\beta + \alpha\gamma + \beta\gamma = \frac{c}{a} \]
\[ \alpha\beta\gamma = -\frac{d}{a} \]

Identify the coefficients from \( P(x) = 3x^3 - x^2 - 6x - 9 \):

\[ a = 3, \quad b = -1, \quad c = -6, \quad d = -9 \]

Step 2: Combine the Reciprocal Fractions

Notice that you cannot simply flip the individual roots. You must express the sum of reciprocals over a common denominator \( \alpha\beta\gamma \):

\[ \frac{1}{\gamma} + \frac{1}{\beta} + \frac{1}{\alpha} = \frac{\alpha\beta + \alpha\gamma + \beta\gamma}{\alpha\beta\gamma} \]

Step 3: Evaluate Numerator and Denominator

Now compute each part using the coefficients \( a = 3, c = -6, d = -9 \):

• Numerator (sum of pairwise products):
\[ \alpha\beta + \alpha\gamma + \beta\gamma = \frac{c}{a} = \frac{-6}{3} = \mathbf{-2} \]
• Denominator (product of roots):
\[ \alpha\beta\gamma = -\frac{d}{a} = -\left(\frac{-9}{3}\right) = -(-3) = \mathbf{3} \]

Substitute these into the compound fraction:

\[ \frac{\alpha\beta + \alpha\gamma + \beta\gamma}{\alpha\beta\gamma} = \frac{-2}{3} = \mathbf{-\frac{2}{3}} \]

\[ -\frac{2}{3} \]

Therefore, Option B is correct.
