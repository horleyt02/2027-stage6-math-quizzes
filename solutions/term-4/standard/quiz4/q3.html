Problem

The diagram shows 6 depots (\(D_1 - D_6\)) connected by a road network with distances (km) between them.

Which of these roads connecting the depots would NOT form part of the minimum spanning tree for this road network?

Worked Solution

Step 1: Prim's Algorithm

To find the Minimum Spanning Tree (MST), we can use Prim's algorithm. We start at any vertex and "grow" the tree by always picking the shortest edge that connects a node currently in the tree to a node currently outside the tree.

Let's start our tree at \( D_1 \).

Step 2: Start growing the tree

From \( D_1 \), the available edges are 6, 3, and 5. We pick the shortest: \( D_1 - D_6 \) (Weight 3).

Now from our tree \(\{D_1, D_6\}\), the available edges to new nodes are 6, 5, 5, 4, 6. The shortest is \( D_6 - D_4 \) (Weight 4).

Step 3: Connect D5

From our tree \(\{D_1, D_6, D_4\}\), we have edges of weight 2, 5, 5, 6, 6 connecting to nodes outside the tree. We select the cheapest: \( D_4 - D_5 \) (Weight 2).

Step 4: Preventing Cycles

Our tree now contains \(\{D_1, D_6, D_4, D_5\}\). We need to connect \(D_2\) and \(D_3\).

Notice the edges \( D_1 - D_5 \) (5) and \( D_5 - D_6 \) (5). Even though they have a weight of 5, they connect nodes that are already inside our tree. Including them would create a loop (cycle), so we must explicitly reject them.

The cheapest valid edge to expand the tree to a new node is \( D_6 - D_2 \) (Weight 5).

Step 5: Finish the Tree

Finally, to connect \( D_3 \), the cheapest available valid edge is \( D_2 - D_3 \) (Weight 3).

The Minimum Spanning Tree is complete. The edge \( D_5 - D_6 \) was explicitly rejected because it would have caused a cycle with nodes already in the tree.

Option D

Therefore, Option D is correct.
