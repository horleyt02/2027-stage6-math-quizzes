Problem

A network of four points \( A \), \( B \), \( C \), and \( D \) is drawn below.

Which of the following network diagrams is NOT an equivalent graph of the network above?

Worked Solution

Step 1: Analyse the Original Graph

The original network is known as a complete graph on 4 vertices (\( K_4 \)).

The defining property of this graph is that every node connects to every other node exactly once. For example, trace the lines from Node A: it has exactly one direct line to B, one to C, and one to D.

Step 2: Evaluate Option B

Let's examine Option B. We are looking for any deviations from the rule we established in Step 1.

Step 3: Conclusion

Because Node A has a double-edge to B, and no edge to C, Option B is not equivalent to the original network.
