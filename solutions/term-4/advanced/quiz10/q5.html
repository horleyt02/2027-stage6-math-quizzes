Problem

The graph of a trigonometric function and linear function are shown below.

Which equation can be used to find the \( x \)-coordinate of the point of intersection of the two functions?

Worked Solution

Step 1: Identify the linear function

The straight line passing through the origin is explicitly given in the diagram.

Linear function: \( y = x \)

Step 2: Identify the trigonometric function

Observe the key features of the curve:

  • It has a \(y\)-intercept at \( (0, 1) \).
  • It has vertical asymptotes at \( x = -\frac{\pi}{2} \) and \( x = \frac{\pi}{2} \).
These features uniquely identify the secant function: \( y = \sec x \).

Step 3: Equate the functions

To find the point of intersection \( P \), we set the two \( y \)-values equal to each other:

\[ x = \sec x \]

Step 4: Rearrange the equation

Use the reciprocal trigonometric identity \( \sec x = \frac{1}{\cos x} \) to rewrite the equation, and then multiply both sides by \( \cos x \):

\[ x = \frac{1}{\cos x} \]
\[ x \cos x = 1 \]

Option C

Therefore, Option C is correct.
